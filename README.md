# FraudTwin-AI

AI-powered transaction fraud detection and risk intelligence system.

## Features
- XGBoost-based fraud prediction
- Transaction risk scoring
- SHAP-based model explainability
- Attack simulation and what-if analysis
- AI-assisted risk assessment
- Transaction investigation workflows

## Tech Stack
- Python
- Streamlit
- XGBoost
- scikit-learn
- Pandas and NumPy
- SHAP

## Run Locally

1. Create and activate a Python virtual environment.
2. Install dependencies:

   `pip install -r requirements.txt`

3. Start the application:

   `streamlit run app.py`

Ensure the required trained model and scaler files are available in the `models/` directory.
